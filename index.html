Race Ahead

An AI learns to race in a video game by rewriting its own driving program between laps, using nothing but the records of its own laps.

Race our AI · play Watch the video · 2:30 Code · GitHub

01 · How an AI drives here

A language model at the wheel, through a driving program

The game is SuperTuxKart, a kart racer. A language model, Jev, does not steer directly. Just before each part of the track, it answers a few questions in words, and a small driving program turns those answers into steering, throttle and brake, 60 times a second.

The driving program

Turns answers into controls

Three small files: the questions Jev is asked, the code that turns answers into steering and throttle, and rules that suggest answers.

This driving program (researchers call it a harness) is what gets better on this page. Jev itself never changes: the same model answers the questions in every lap.

02 · The starting point

A deliberately bad first version

We hand the system a driving program that is bad on purpose: only two questions, no rules, and slow, fixed target speeds. We wrote three such bad starts, called A, B and C.

For comparison we use the game's own AI. It knows the whole track in advance, so it is a strong reference. The system never sees how it drives and never learns from it.

03 · How it learns

One model drives, a second model rewrites the driving program

Between laps, a second language model reads the records of the laps and proposes edits to the three files. Every edit is driven on the track and measured, a reviewer model keeps or rejects each one and writes down why, and the result is driven again. One pass of this loop is a round; the system runs 40 rounds and keeps the best version so far. It practices on 10 tracks and never sees the tracks we test it on later.

    04 · Getting faster

    The same practice track, six laps: how the best version got faster

    The best version of start B after rounds 0, 7, 11, 14 and 40, and the game's own AI, on one of the practice tracks. These are real laps from the experiment, replayed in the game.

    The first version never gets far above 16 m/s. Round 7 raises its target speeds. Round 11 brings in a redesign that slows down only as much as each curve needs. Round 14 lets the kart run flat out on straights (its dip to almost zero is the game putting the kart back after it left the road). Later rounds refine steering and braking, and the final version finishes cleanly.

    06 · Failures stay in the record

    Big redesigns, crashes and repairs are all kept

    The cyan line is the best version so far; each square on it is a round that made it faster (the number is its total time in seconds). A big redesign is built on a side track below the line and joins the main line only once it is faster and the reviewer agrees. A red cross is a round where the new version crashed. In rounds 1–5 a bold rewrite crashed on every track; each error message went back to the system until it gave the redesign up. In round 20 another redesign crashed on every track, was repaired in round 21, and joined the main line. Click any side track.
